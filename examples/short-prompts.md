# Short Prompt Examples

Each line can be passed after `npm run generate -- --prompt`.

```text
Japanese for Tunisians — A0–B2 dialogue-first study and travel learning
Spanish for Japanese learners — A1–B2 professional collaboration and reading practice
Chinese for Spanish speakers — A0–B2 everyday, academic, and project communication
```

The parser produces a transparent starter package. It does not claim to write a finished production system, deploy an application, or create credentials.
